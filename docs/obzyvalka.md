# Обзывалка

Обзывалка — локальная функция AyuGram Desktop, которая использует Ollama для анализа новых сообщений выбранного пользователя в выбранном чате.

## Требования

- Ollama запущена на этом компьютере.
- Модель доступна в Ollama под именем `qwen3-4b-local`.
- Локальный API Ollama доступен по адресу `http://127.0.0.1:11434`.

Проверка модели:

```powershell
ollama list
ollama ps
```

## Настройка

Откройте **Настройки → AyuGram → Обзывалка**:

1. Включите функцию.
2. Выберите чат, в котором нужно отслеживать сообщения.
3. Выберите пользователя, чьи сообщения нужно обрабатывать.
4. Оставьте режим **А — Автоматический ответ** или выберите **Б — Локальная подмена**.
5. При необходимости измените адрес Ollama или имя модели.

Режим А используется по умолчанию.

## Режимы

- **А — Автоматический ответ:** если модель определит прямое оскорбление, AyuGram отправит преобразованный текст ответом на исходное сообщение от вашего аккаунта.
- **Б — Локальная подмена:** преобразованный текст отображается только в вашем клиенте. Сообщение в Telegram не редактируется и другим участникам показывается исходный текст.

## Ограничения и защита

- Обрабатываются только новые непрочитанные текстовые сообщения не старше 60 секунд, чтобы не отвечать на старую историю при открытии чата.
- Обрабатываются только выбранные чат и пользователь.
- Собственные исходящие сообщения игнорируются.
- Одновременно выполняется не более четырёх запросов к Ollama.
- Автоматические ответы ограничены интервалом 2,5 секунды.
- Если Ollama недоступна или модель вернула некорректный результат, сообщение не отправляется.
- Текст передаётся на указанный адрес Ollama. При стандартной настройке это локальный адрес компьютера.
